# MDY-wiki 站点设计文档

- 日期：2026-10-09
- 状态：已获用户批准，进入实施
- 站点地址：https://givemeasmileqaq.github.io/MDY-wiki/

## 背景与目标

MDY-wiki 是 cnapex-MDY 大家庭史记，以纯 Markdown 在 GitHub 仓库维护（`队伍线/个人线/其他/`，每条目一个 `main.md`），社区通过 Pull Request 投稿。目标：在不改变现有内容组织方式的前提下，把仓库内容发布为可检索、可浏览的网站，push 到 main 后自动更新。

## 已确认决策

| 决策项 | 结论 |
|---|---|
| 框架 | VitePress（成熟稳定、界面现代、中文文档完整） |
| 首页 | 内置 home 布局（标题 + 夺冠照 + 导航卡片） |
| 部署 | GitHub Pages 默认域名 + GitHub Actions 自动构建 |
| 内容位置 | 保持现有目录原位，不搬家，工程文件最小化新增 |

## 仓库结构设计

```
新增：
├── .github/workflows/deploy.yml   # push main 自动构建部署 Pages
├── .gitignore                     # node_modules / dist / cache
├── package.json                   # vitepress 依赖与 scripts
├── .vitepress/
│   ├── config.mts                 # 站点配置（导航、搜索、侧边栏自动生成、mermaid）
│   └── theme/                     # 主题定制（品牌色、细节样式）
├── index.md                       # 网站首页
├── 队伍线/index.md                # 分区索引页（7 队）
├── 个人线/index.md                # 分区索引页（19 人）
├── 其他/index.md                  # 分区索引页（3 篇）
├── 投稿指南.md                    # 如何 PR、格式说明、模板入口
└── 工程文档/                      # 本设计文档与使用说明（站点排除）

更新：
├── 目录.md                        # 空骨架填充为全站总目录

不变：
└── 队伍线/ 个人线/ 其他/ 模板/ images/ README.md 目录.pdf（内容原位）
```

排除项（`srcExclude`）：`README.md`（GitHub 专用）、`工程文档/**`、`node_modules/**`。

## 页面与导航设计

- **首页**：`layout: home`。hero 标题「MDY 史记」，配 25ewc 夺冠照；features 卡片：个人线 / 队伍线 / 其他 / 投稿指南。
- **顶部导航**：首页 ｜ 目录 ｜ 个人线 ｜ 队伍线 ｜ 其他 ｜ 投稿指南。
- **侧边栏**：在 `config.mts` 中用 `node:fs` 扫描目录自动生成（`队伍线/*/main.md` → 队名条目），新增条目无需改配置。
- **大纲**：右侧 outline 显示 `####` 级（长文可跳转「IG时期 / MDY1.0 / …」）。
- **搜索**：内置本地搜索，配置中文分词 tokenize 与中文 UI。
- **目录页**：全站索引（分类列表链接）。
- **投稿指南页**：PR 流程、内容格式（`## 对象` / `### 主线` / `#### 时期` / 参考文献锚点）、模板入口。

## 内容兼容清单（不改任何现有正文）

| 现有写法 | 处理 |
|---|---|
| `[冠军](#ref-6)` + `<a name="ref-N">` | 原样保留，锚点跳转兼容 |
| `<font color="green/red">` | 原样渲染（内联 HTML 透传） |
| 相对路径图片 `images/6.jpg` | VitePress 自动处理并复制产物 |
| mermaid 代码块（`其他/人物关系.md`） | `vitepress-plugin-mermaid` 渲染 |
| `main.pdf` / `目录.pdf` 链接 | 保留、可下载 |
| 0 行空条目 | 生成空白页，不报错 |
| 中文文件名/路径 | 原样支持 |

## 部署流程

1. 一次性设置：仓库 Settings → Pages → Source 选 `GitHub Actions`。
2. 此后 push/merge 到 main 自动构建部署，约 1~2 分钟更新。
3. 本地预览：`npm run docs:dev`。

## 实施步骤与验证

1. 设计文档 → 验证：文件写入 `工程文档/`。
2. npm 工程初始化 → 验证：`package.json`/`.gitignore` 生成，vitepress 安装成功。
3. `config.mts` + 主题 → 验证：`npm run docs:build` 无错误。
4. 页面编写（首页/索引/指南/目录） → 验证：各页面出现在产物中。
5. 本地构建 + 浏览器验证清单：
   - `#ref-N` 锚点跳转；
   - `<font color>` 渲染；
   - mermaid 图渲染；
   - 中文搜索可命中；
   - 中文路径页面可访问；
   - 空条目页正常。
6. GitHub Actions workflow → 验证：YAML 语法与步骤完整（真实部署需用户推送后观察）。
7. 使用说明文档 → 验证：写清本地预览、投稿新条目、Pages 设置、常见问题。
